Measured boundaries stay visible

FontWitness measures ordinary light-DOM TextNodes on one explicitly selected page. All matches are checked, overlap is canonical, and incomplete measurements remain partial. CSS declarations are diagnostic; actual engine identities drive contract evaluation.

Glyph counts are raw per-call observations, not character counts or correctness scores. The pinned Chromium is supported. Iframes, shadow text, canvas, SVG, generated content, and control values are outside v0.1.1.
